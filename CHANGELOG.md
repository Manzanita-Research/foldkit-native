# foldkit-native

## 0.1.0

### Patch Changes

- The first versioned source of FoldKit Native: FoldKit on gpuix (`foldkit-gpuix`), the `@foldkit-native/ui` components and the happy-dom mirror. The three packages build to compiled ESM and type declarations (`npm run pack:packages`), share one version, and stay `private`: nothing is published to npm. Changesets manages the version; GitHub source releases stay off until a maintainer sets the `RELEASES_ENABLED` repository variable.
